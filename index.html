📜 종료된 Cycle 히스토리

조회할 과거 Cycle을 선택해주세요.

1. 콘텐츠별 고정 출석 시간 추가 (항목당 최대 10개)

매일 또는 원하는 요일(복수 선택 가능)과 시작~마감 시각을 지정하면 해당 시간마다 자동으로 출석이 열립니다.

출석 요일 선택

월드보스 0 / 10

2. 현재 Cycle 정산 및 종료

종료를 누르면 현재까지의 모든 유저 점수가 과거 기록(History)으로 영구 저장되며, 현재 누적 점수는 0점으로 초기화됩니다.

※ 등록된 고정 출석 시간(요일·시간대 슬롯, 각 최대 10개)은 다음 Cycle에서도 그대로 유지됩니다.

과거 Cycle 기록 삭제

과거 Cycle 기록을 삭제하면 남은 기록 기준으로 현재 Cycle 번호가 자동으로 재조정됩니다. (예: Cycle #1 삭제 시 현재 Cycle #2 → #1로 변경)

저장된 과거 Cycle 기록이 없습니다.

3. 유저별 출석 기록 수동 추가 / 삭제 (시간 무관)

출석 시간이 지났거나 별도 보상이 필요한 경우 관리자는 특정 유저의 참여 내역을 직접 추가하거나 잘못된 기록을 삭제할 수 있습니다.
